# Fleet Future Evaluations

This directory is for concepts that may be worth revisiting but are not current product authority.

Use it to preserve useful historical design work without silently expanding Fleet 1.0.

## Status vocabulary

- **FUTURE EVALUATION** — potentially useful, not accepted current scope.
- **DEFERRED** — accepted direction intentionally postponed.
- **HISTORICAL** — provenance/context only.
- **REJECTED** — explicitly not current direction.
- **CANDIDATE** — needs reconciliation or a decision.
- **UNRESOLVED** — contradictory evidence or unclear chronology.

A document in this directory is not a requirement, roadmap commitment, or implementation authorization.

## Promotion rule

Promote an idea into current project truth only through the appropriate authoritative surface:

- Fleet-wide architecture/scope: Fleet ADR/decision/roadmap;
- Vincent behavior: Vincent requirement/ADR/roadmap/issue;
- CIC Station behavior: CIC Station requirement/ADR/roadmap/issue.

When promoted, link the accepted decision and leave enough historical context here to explain the transition if useful.

## Historical Mission Control material

Older Mission Control/generalized orchestrator designs should normally land here or under `docs/history/` during chat reconciliation unless current Git already proves they are active Fleet scope.

Detailed historical design is evidence of prior thought, not evidence of current acceptance.
